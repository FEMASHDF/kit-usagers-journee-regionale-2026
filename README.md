# Kit de communication usagers — Journée régionale 2026

Page statique prête pour GitHub Pages. Elle contient les aperçus PNG, le courrier Word fourni par FEMAS, les textes à copier et une archive du kit complet.

## Publier

1. Déposer le contenu de ce dossier à la racine d’un dépôt GitHub public. Conserver tous les fichiers ensemble.
2. Dans **Settings → Pages**, choisir **Deploy from a branch**.
3. Choisir la branche contenant ces fichiers, puis **/ (root)** et **Save**.
4. Utiliser le lien affiché par GitHub Pages une fois la publication terminée.

## Modifier les supports

Remplacer les fichiers à la racine du dépôt en conservant leurs noms. Recréer `kit-complet.zip` pour que le téléchargement global corresponde aux supports disponibles.

Le courrier fourni est modifiable dans Word. Aucun aperçu PDF n’est annoncé : aucun PDF du courrier n’a été fourni. L’affiche est proposée au format PNG d’origine.

Les textes de publication et d’invitation sont éditables dans `index.html`. La page utilise des polices Google Fonts avec une police de secours locale.
